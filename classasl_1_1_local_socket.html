LocalSocket Class Reference
Socket communication

Detailed Description

A Local or Unix socket for inter-process communication within a machine.

Works similar to a TCP socket but it is bound to a local path in the file system.

Used to be Unix/Linux-only but is also supported on recent Windows 10+ versions (need to enable CMAKE_SOCKET_LOCAL on Windows)

LocalSocket server;
server.bind("/dir/comm.sock");
server.listen();
LocalSocket client = server.accept();
...
LocalSocket client;
client.connect("/dir/comm.sock");
client << "Hello\n";

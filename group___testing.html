Testing

Detailed Description

Tiny testing functionality.

The ASL_TEST_ENABLE_MAIN() macro adds testing functionality and creates a main function that runs all defined tests. Use the ASL_TEST_ENABLE() macro if you will provide your own main function. Use one of these macros but only in one source file (.cpp) if your tests project has several.

#include <asl/testing.h>
ASL_TEST_ENABLE_MAIN()
ASL_TEST(Car)
{
Car car;
ASL_ASSERT(car.isStopped());
ASL_EXPECT(car.numWheels(), >, 2);
}
ASL_TEST(Volume)
{
Sphere sphere(1.0);
ASL_EXPECT_NEAR(sphere.volume(), 4.1888, 1e-3);
}
